
# AI M

AI M is a responsive Arabic and English AI chat interface.

## Features
- Responsive mobile and desktop design
- Arabic RTL and English LTR
- New chat and recent chat list
- Prompt suggestions
- Cloudflare Pages API endpoint

## Deployment

Deploy this repository using Cloudflare Pages.

- Production branch: main
- Build command: leave empty
- Build output directory: public

The chat API starter does not connect to an AI provider yet.
Configure a provider securely using Cloudflare environment secrets.
Never put API keys in public files.
